# Discover South Africa — starter website

Open `index.html` in a browser. It is a responsive, single-page prototype with destination discovery, route cards, a trip starter, a chatbot demo and an interactive virtual-place-preview overlay.

## Important prototype notes
- The chatbot currently uses local demo responses. Connect it to a secure backend and an AI API for a production assistant; do not put API keys in browser JavaScript.
- The circular preview button opens a 360-tour-style interface with clickable hotspots. The current background is a representative photograph, not an actual 360-degree panorama. Replace it with licensed 360° panoramas and a viewer such as Pannellum or Marzipano to enable drag-to-look tours.
- Destination cards and suggested routes are starter content. Verify information, permissions, images, operators, prices, accessibility and safety details before launch.
- Images are loaded from Unsplash URLs and fonts from Google Fonts, so the prototype requires internet access for those assets.
